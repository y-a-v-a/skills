social-preview

A Claude Code skill that turns your repo into a polished GitHub social preview image — a 1280×640 PNG in the project's own visual language, ready for the repo card on X, Slack, and anywhere else the link unfurls.

your-project

One line that says what it does.

by You

The anatomy of every card: big name, short tagline, quiet byline, decorative motif — all inside the 40pt safe area.

How it works

  1. Read the repo

    Scans README.md and package.json for what the project is, and distills a tagline of ≤ 60 characters. For webapps it also reads the CSS and HTML to pick up theme colors, fonts, and layout idioms.

  2. Write a throwaway HTML card

    A single 1280×640 page in the scratchpad — never in your repo. The design echoes the project's own look; CLIs and libraries get a tasteful typographic card instead.

  3. Screenshot with headless Chrome

    One command, no dependencies installed, nothing built. The output size is verified with sips — exactly 1280×640 or it doesn't ship.

  4. Iterate until you approve

    You see the PNG, react, the HTML gets tweaked, re-shot, resent. When approved, the throwaway HTML is deleted and social-preview.png stays in the repo root.

The rules baked in

Exact canvas

1280×640, GitHub's recommended size. No scrollbars, no margins, verified after every shot.

40pt safe area

Name, tagline, and byline stay 40pt (~54px on the canvas) from every edge — some surfaces crop. Decoration may bleed.

Legible at half size

Cards usually render at 640×320 on retina screens, so even the smallest text is ≥ 28px on the canvas.

Your project's look

Theme colors, fonts, and motifs come from the repo itself — not from a generic template.

The screenshot command

"$CHROME" --headless --disable-gpu \
  --screenshot="<repo>/social-preview.png" \
  --window-size=1280,640 \
  --force-device-scale-factor=1 \
  --hide-scrollbars \
  --virtual-time-budget=5000 \
  "file:///<scratchpad>/social-preview.html"
One manual step remains: GitHub has no API for social previews. Upload the PNG by hand at Settings → General → Social preview.
